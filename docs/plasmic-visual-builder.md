# Plasmic — визуальный конструктор страниц

Plasmic — это визуальный редактор (drag-and-drop): блоки двигаешь мышкой, видишь
результат сразу, контролируешь раскладку (что слева, что справа, в колонки).
Страницы, которые ты собираешь в Plasmic Studio, рендерятся прямо в этом
Next.js-приложении.

В отличие от headless-WordPress (где раскладка задаётся в коде, а в админке
меняется только контент), здесь раскладку и контент ты задаёшь визуально сам.

## Что уже сделано в коде (этот PR)

- `src/plasmic-init.ts` — инициализация загрузчика Plasmic (Project ID + токен из env).
- `src/plasmic-init-client.tsx` — клиентский провайдер (`PlasmicRootProvider`).
- `src/app/studio/[[...catchall]]/page.tsx` — страница-обработчик: всё, что ты
  создашь в Plasmic, автоматически появляется под адресом `/studio/...`.
- `src/app/plasmic-host/page.tsx` — «host»-страница: позволяет Plasmic Studio
  рисовать поверх дизайна этого приложения (опционально, для code-компонентов).

Ничего из существующего кода не меняется. Все страницы Plasmic живут под `/studio`,
поэтому не конфликтуют с твоими маршрутами (`/`, `/journal`, `/about` и т.д.).

## Шаг 1. Создать проект в Plasmic

1. Зарегистрируйся на https://studio.plasmic.app (бесплатно, можно через Google).
2. Создай новый проект (New project → пустой/Blank).
3. Внутри проекта создай страницу (Page) и поставь ей маршрут (route) `/`.

## Шаг 2. Взять Project ID и публичный токен

- **Project ID** — в адресной строке Studio:
  `https://studio.plasmic.app/projects/PROJECTID` → это `PROJECTID`.
- **Public API token** — нажми кнопку **Code** в верхней панели Studio; токен
  показан там (это *публичный* токен только для чтения, не секрет).

## Шаг 3. Прописать env-переменные

Создай (или дополни) файл `.env.local` в корне проекта:

```
NEXT_PUBLIC_PLASMIC_PROJECT_ID=сюда-Project-ID
NEXT_PUBLIC_PLASMIC_API_TOKEN=сюда-публичный-токен
```

Перезапусти dev-сервер (`Ctrl+C`, затем `npm run dev`) — env читается только при старте.

## Шаг 4. Посмотреть результат

- Открой `http://localhost:3000/studio`.
- Страница Plasmic с маршрутом `/` покажется здесь.
- Страница с маршрутом `/about-us` будет на `http://localhost:3000/studio/about-us`,
  и так далее (маршрут из Plasmic добавляется после `/studio`).

Меняешь дизайн в Plasmic → жмёшь **Publish** → обновляешь страницу → видишь изменения.

## (Опционально) Редактировать поверх своего дизайна — «App host»

Чтобы в Plasmic Studio был виден реальный дизайн этого сайта (шрифты, стили,
твои React-компоненты), укажи в настройках проекта Plasmic
(Project → Settings → Host URL / App host):

```
http://localhost:3000/plasmic-host
```

После этого холст Plasmic будет рисовать в контексте приложения.

## Продакшен

Когда зальёшь на Netlify — пропиши те же `NEXT_PUBLIC_PLASMIC_PROJECT_ID` и
`NEXT_PUBLIC_PLASMIC_API_TOKEN` в переменных окружения Netlify. В отличие от
LocalWP, Plasmic живёт в облаке, поэтому продакшен-сайт достучится до него без
дополнительного хостинга. Для автообновления сайта при публикации в Plasmic
можно настроить deploy-webhook Netlify.
